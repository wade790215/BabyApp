# 素材授權

## 卡片佔位圖：OpenMoji

`Assets/BabyApp/Art/Cards/` 底下目前的 35 張 PNG 來自 OpenMoji，是**暫時的佔位圖**，之後會被 AI 生成的圖用同樣的檔名覆蓋。

- 來源：[OpenMoji](https://openmoji.org) — the open-source emoji and icon project
- 授權：[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- 建議標註：All emojis designed by OpenMoji – the open-source emoji and icon project. License: CC BY-SA 4.0
- 抓取腳本與碼點對照：`tools/fetch-openmoji-placeholders.sh`、`tools/openmoji-map.txt`

**這代表什麼**

- 自己家裡裝著玩：完全沒問題。
- 要給別人安裝或上架：只要 App 裡還留著任何一張 OpenMoji 的圖，就要在 App 內（例如設定頁或關於頁）放上面那行標註；而且 **BY-SA 的 ShareAlike 條款**要求你基於這些圖改作的東西也要用同樣授權釋出。
- 最乾淨的做法：**發佈前把 35 張全部換成 AI 圖**，這份文件就可以整段刪掉。

`vehicle_excavator`（挖土機）沒有對應的 emoji，所以**沒有佔位圖**，會是第一張需要 AI 生成的卡。
