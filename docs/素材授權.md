# 素材授權

## 卡片圖與吉祥物：Google Gemini 生成

`Assets/BabyApp/Art/Cards/`（47 張）、`Art/Covers/`（4 張）與 `Art/Mascot/`（5 張）全部是 2026-10-23 用 Google Gemini 的「建立圖像」生成、再用 `tools/knockout-white.py` 去白底的。顏色組 8 顆色球是程式畫的。

AI 生成圖的著作權歸屬目前各國仍有爭議；自己家裡用沒有問題。要上架的話請看當時 Google 的 Gemini 使用條款（生成內容可以商用，但不保證不侵權）。這些圖裡沒有任何現有角色或商標。

OpenMoji 的佔位圖已全部換掉，不再需要標註。

## 字體

見 README「字體授權注意」一節：開發期借用 Windows 標楷體，發佈前換 Noto Sans TC。

## 介面圖示

`Art/UI/` 裡的箭頭與條紋是程式畫出來的（`BabyAppUiSprites.cs`），沒有授權問題。

## 名稱語音：Windows 語音合成

`Assets/BabyApp/Audio/Cards/` 底下的 `{cardId}.wav`（中文）與 `{cardId}_en.wav`（英文）是用 Windows 內建的 Microsoft Hanhan（zh-TW）與 Microsoft Zira（en-US）合成的，腳本是 `tools/make-voices.ps1`。

這是你自己電腦產出的檔案，自己用沒問題；微軟對 SAPI 語音合成輸出的再散佈沒有明確授權，**要上架前建議換成自己錄的或可商用的 TTS**。對 2～3 歲來說，爸媽的聲音本來就比任何合成聲音好。
