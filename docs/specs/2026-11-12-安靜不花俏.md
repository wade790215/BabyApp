# BabyApp「安靜不花俏」方案：聲音與動畫手感（2026-11-12，planner 輸出）

> 背景：使用者決定把整體感覺往 Pok Pok Playroom 靠（研究報告 `docs/research/2026-11-12-PokPok風格.md`）。這份只處理「聲音與動畫手感」這一半；畫風（無框線色塊）另外走素材重生成。planner 唯讀，沒有改任何檔案、沒跑任何選單。

先講結論：
- **背景音樂其實從來沒響過。** `VoiceService.musicClip` 在場景裡是 `{fileID: 0}`（`Main.unity:21964`），Builder 沒有接它，專案裡也沒有任何音樂檔。設定頁那個「音樂」開關一直是個沒作用的空開關。
- **改合成參數之前先知道一件事：改了也不會生效。** `BabyAppSfxGenerator.Ensure()` 只要檔案已存在就直接沿用，所以光改參數、重跑選單 3，聽到的還是舊聲音。
- 要讓新聲音生效，必須換新檔名，或先把舊檔刪掉。

---

## 1. 需求摘要與假設

**目標**：把聲音和動畫往 Pok Pok 的方向調，也就是沒有配樂、音效短而低而圓、動畫慢而小、沒有星星噴發。畫風（無框線色塊、拿掉陰影）不在這份方案裡。

**假設**：
- **A1**：「沒有獎勵迴圈」不等於「答對沒反應」。答對保留三樣：小熊換開心表情、一聲柔和的木頭敲擊、念出名稱。拿掉的是星星、上行琶音和大幅度彈跳。
- **A2**：`Builder` 裡的陰影（`AddShadow`、`ShadowColor` α 0.16、位移 -6）算畫風那一半，這次不動。
- **A3**：小熊台詞（例如「答對了！好棒！」）要不要改內容，不在這次範圍，列在第 5 節請使用者決定。
- **A4**：Pok Pok 沒有公開任何動畫時長或曲線數字（研究報告第 8 節）。下面的數值都是建議起點，要靠使用者實際看、聽再微調。

### 2.3 一個要順手修的既有 bug

`Mascot.JumpRoutine` 每次起跳時，都把「當下位置」記成落地點 `home`。在空中被再叫一次 `Jump()`，落地點就變成半空中，小熊會越來越高。數數連點、拼圖連放時很容易遇到。只要把跳幅改小，就該一起修掉。

## 3. 五個問題

**Q1 背景音樂：建議整個拿掉，不只是預設關閉。**
- 預設本來就是關的（`AppSettings.cs:59` 的 `GetInt(MusicKey, 0)`）。
- 場景裡沒有音樂檔，開關打開也不會響，家長會以為壞了。
- Pok Pok 也明確不放配樂。

要一起處理：設定頁刪 music 那一列與 `SettingsScreen.musicToggle`（`:49`、`:100`）；刪 `Strings["music"]`（只有 Builder 第 1206 行用到；`Strings.Get` 找不到鍵會回傳鍵名，不會崩潰）；刪 `AppSettings.MusicEnabled` 與 `MusicKey`（舊裝置殘留的 PlayerPrefs 無影響）；刪 `VoiceService` 的 `musicSource`、`musicClip`、`musicVolume` 和 `ApplySettings` 裡的音樂邏輯；Builder 的 `CreateAppRoot` 少建一個 AudioSource 並拿掉 `("musicSource", …)` 接線。

**Q2 音效：先調合成參數，實物錄音當第二批。**
合成成本零、可退回，能馬上解決「高、尖、往上走」。用兩個不成整數倍的正弦波快速衰減（模態合成）做「木塊敲一下」不難。實物錄音要下載檔案（先問使用者）、剪頭尾。所以第 4 步先合成，不滿意再第 6 步換錄音；第 4 步先把檔名與副檔名接法定好。

**Q3 星星與 tada：星星全部拿掉，tada 換成柔和的「啵」，答對時只保留一個 `PlayCorrect`。**
- 答對（找一找、配對）、拼完、數完：小熊開心表情＋16px、0.55 秒的小跳（點頭感）；一聲 G4 木琴／木魚般的音（取代 sparkle）；台詞、叫聲、名稱照舊。
- 卡片頁點卡片：不再放 sparkle，叫聲和名稱就是反應，加上縮小的 TapReaction。
- 數數每點一個：拿掉 sparkle，只剩念數字和咔滋，數完最後一個才 `PlayCorrect`。
仍符合「我按下去，世界有反應」，只是不再層層疊加。

**Q4 動畫數值：**

| 項目 | 現在 | 建議 |
|---|---|---|
| Pulse | 1.12 / 0.28 秒 | `scaleUp` 1.05、`duration` 0.40 秒（100 毫秒時已放大約 3.5%） |
| TapReaction：Bounce | 14% / 0.3 秒 | 6% / 0.45 秒 |
| TapReaction：Wiggle | 8°、4π / 0.45 秒 | 4°、3π / 0.6 秒 |
| TapReaction：Squash | 15% / 0.4 秒 | 6% / 0.55 秒 |
| TapReaction：Spin | 轉 360° | **刪除**，隨機改成三選一、仍不連續重複 |
| Mascot 呼吸 | 每秒 2.2 弧度 / 0.025 | 每秒 1.4 弧度（約 4.5 秒一週期）/ 0.015 |
| Mascot 跳 | 0.4 秒 / 40px | 0.55 秒 / 16px，並修掉往上漂的 bug |
| CardDoor 抖動 | 每 2.5 秒 / 4% / 0.3 秒 | 每 6 秒 / 2.5% / 0.6 秒 |
| CardDoor 打開 | 0.3 秒、先放大到 1.08 | 0.45 秒，不先放大：1 → 0.9（SmoothStep），透明度 1 → 0 |
| Touch Wiggle | 7° / 0.4 秒 | 4° / 0.6 秒 |
| HelpFind 對的那張跳 | 8% | 5%（0.9 秒不變） |
| BounceSample | 6% / 0.5 秒 | 4% / 0.6 秒 |
| Puzzle 底盤 | 8% / 0.6 秒 | 4% / 0.8 秒 |

**曲線**：`unity_reflect` 確認 `Mathf.SmoothStep(float, float, float)` 與 `AnimationCurve.EaseInOut` 都存在。程式裡直接用 `Mathf.SmoothStep(0,1,p)`，不新增 `AnimationCurve` 序列化欄位（Builder 不方便設定，還多重建依賴）。「鼓起再回來」保留 `Mathf.Sin(p*Mathf.PI)`；單向收尾用 SmoothStep。

**Q5**：第 1～5 步只改程式和參數，第一批做。第 6 步（實物錄音）要等素材且先經使用者同意下載。
